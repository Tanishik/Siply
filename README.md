# 🍹 Siply — E-Commerce Smoothie Ordering App

A sleek, modern cross-platform e-commerce Flutter application designed for seamless smoothie catalog browsing, dynamic cart customization, and real-time total price calculation. 

Built with predictable state management using **BLoC / Cubit** architecture.

---

## ✨ Features

- **Product Showcase:** Browse smoothie items complete with detailed descriptions, ratings, and price tags.
- **Dynamic Quantity Adjustment:** Custom control buttons to increment/decrement item quantities both on details pages and directly within the cart tiles.
- **Real-time Cart & Total Calculation:** Instant reactive state updates emitting real-time cost totals upon cart modifications.
- **Clean UI & Responsive Layout:** Smooth transitions, structured bottom navigation bar, and clean visual hierarchy tailored for modern mobile devices.

---

## 🛠️ Tech Stack & Architecture

- **Framework:** [Flutter](https://flutter.dev/) (Dart)
- **State Management:** `flutter_bloc` (Cubit Pattern)
- **Architecture:** Unidirectional Data Flow (State & Event emission with immutable models)
- **UI Components:** Custom Cards, Dynamic `ListTile` views, and contextual modal sheets
